# BatuMove UX pass

Изменения в этой версии:

- На карте в обычном состоянии добавлена нижняя карточка с 3 ближайшими остановками.
- Для ближайших остановок показываются расстояние и примерное время пешком.
- Карточка выбранной остановки дополнена временем пешком и номером остановки (если он есть).
- Поиск назначения получил кнопку быстрой очистки.
- Тексты экрана карты и trip planner перенесены в string resources.
- Добавлены переводы новых строк для English, Русский, Українська и ქართული.
- Варианты прямой поездки теперь показывают расстояние до стартовой остановки и примерное время пешком.
- В деталях маршрута под переключателем направления показывается конечная остановка текущего направления.
- Статус автобусов в деталях маршрута отмечен как live data при успешном realtime-состоянии.
- Карточка выбранного автобуса локализована и показывает его направление.
- Единицы расстояния на изменённых экранах локализованы.

Что намеренно не добавлялось без дополнительной backend/фоновой логики:

- push-уведомления «автобус скоро»;
- маршруты с пересадками;
- исторический прогноз ETA по времени суток;
- достоверный возраст GPS-точки каждого автобуса (API-модель сейчас не содержит timestamp позиции).

Проверка:

- XML string resources проверены парсером, дубликатов нет.
- Kotlin-файлы проверены локальным компилятором на синтаксические ошибки.
- Полная Gradle Android-сборка в рабочей среде не выполнена: wrapper требует загрузить Gradle 9.4.1 с services.gradle.org, а интернет для shell-среды недоступен.
